# 厨房情况

用户自己的厨房条件和习惯。这里随时可能更新，与规格书冲突时以这里为准。

## 厨具

- 火力不强的炉具
- 炒锅 / 平底锅、小锅
- 空气炸锅（内侧约 19.5×20cm）
- 烤箱
- Instant Pot
- 煮蛋器（小蒸锅）
- 大不锈钢蒸锅
- 和面机
- 碎肉机
- 手持搅拌机

代码里的 `Equipment` 只有菜谱实际用到的类型，用到新设备时再加。Instant Pot、和面机、碎肉机目前没有对应菜谱。没有用户的配方时，不编压力时间之类的参数。

## 肉类处理

腌好后按一天一袋冷冻，解冻后直接烹饪。规格书写的「冷冻前保持原味」已作废。

腌法可以换，`src/domain/references.ts` 里的配方只是参考。鸡胸肉和牛肉碎一天一袋 1 lb（约 454g），对应默认的「做 2 份吃两顿」，菜谱默认用量也是 454g。猪里脊、鱼片、牛肉片的默认用量还是 500g，一袋多重没有确认过。

## 旧饮食计划

`06-Life/Health` 里的每日餐单、周结构、热量目标、增肌减脂阶段不进 App，只取菜、食材和营养事实。
